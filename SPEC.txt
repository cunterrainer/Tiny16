=== INSTRUCTIONS ===
0:   LOAD   reg/addr16, reg -> reg = *addr16/*reg # reads 2 bytes
1:   STORE  reg, reg/addr16 -> *addr16/*reg = reg # stores 2 bytes
2:   LOADB  reg/addr16, reg -> reg = *addr16/*reg # reads 1 byte
3:   STOREB reg, reg/addr16 -> *addr16/*reg = reg # stores 1 byte
4:   MOV    imm16/reg, reg   -> reg = imm16/reg
5:   ADD    imm16/reg, reg   -> reg = reg + imm16/reg
6:   SUB    imm16/reg, reg   -> reg = reg - imm16/reg
7:   MUL    imm16/reg, reg   -> R0:R1 = reg * imm16/reg (unsigned)
8:   IMUL   imm16/reg, reg   -> R0:R1 = reg * imm16/reg (signed)
9:   DIV    imm16/reg, reg   -> R1 = reg / imm16/reg, r0 = reg % imm16/reg (unsigned)
10:  IDIV   imm16/reg, reg   -> R1 = reg / imm16/reg, r0 = reg % imm16/reg (signed)
11:  JMP    reg/addr16       -> PC = reg/addr16
12:  JE     label            -> PC = label if equal         else NOP
13:  JNE    label            -> PC = label if not equal     else NOP
14:  JL     label            -> PC = label if less          else NOP (signed)
15:  JLE    label            -> PC = label if less equal    else NOP (signed)
16:  JG     label            -> PC = label if greater       else NOP (signed)
17:  JGE    label            -> PC = label if greater equal else NOP (signed)
18:  JA     label            -> PC = label if above         else NOP (unsigned)
19:  JAE    label            -> PC = label if above equal   else NOP (unsigned)
20:  JB     label            -> PC = label if below == 0    else NOP (unsigned)
21:  JBE    label            -> PC = label if below equal   else NOP (unsigned)
22:  CMP    imm16/reg, reg   -> Set flag (RF) if equal / greater / less (reg - imm16/reg)
23:  HALT                    -> Halt execution and wait for vblank interrupt
24:  BRK                     -> Stop execution, terminate program
25:  NOP                     -> No operation
26:  EXTBL reg, reg          -> reg = reg & 0x00FF extract low byte
27:  EXTBH reg, reg          -> reg = (reg >> 8) & 0x00FF
28:  INSBL reg, reg          -> reg = (reg & 0x00FF) | ((reg8 & 0x00FF) << 8) Insert into low 8 bits
29:  INSBH reg, reg          -> reg = ((reg & 0xFF) << 8) | (reg >> 8) Insert into high 8 bits
30:  SWAPB reg               -> reg = ((reg & 0xFF) << 8) | (reg >> 8) Swap high/low bytes
31:  AND   imm16/reg, reg    -> reg = reg & imm16/reg
32:  OR    imm16/reg, reg    -> reg = reg | imm16/reg
33:  XOR   imm16/reg, reg    -> reg = reg ^ imm16/reg
34:  NEG   reg               -> reg = -reg

* imm16 are the bytes immediately following the instruction byte in memory

=== ENCODING ===
We are using a little endian architecture

The binary starts at main and has to start with an instruction,
then we just execute these instructions, e.g. the binary looks like:
mov 1 r0 add 2 r0 sub 3 r0

=== Addresses ===
   0 - 6FFE Are free to use
6FFF - FFFF Correspond to 1 byte per pixel pixel coordinates for a 256x144 screen
